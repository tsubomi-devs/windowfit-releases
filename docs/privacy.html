プライバシーポリシー

Windowfit は、お客様の個人情報を収集しません。

アプリが読み取るもの

  • 前面のウィンドウの位置と大きさ（動かすときだけ）

アプリが通信するとき

  • アップデートの確認 — 1 日 1 回、GitHub（github.com）にある最新版の一覧を読みます。お客様を識別する情報は含みません。設定画面でオフにできます。

Mac に保存されるもの

  • 設定（ショートカットなど）。macOS の設定ファイルに保存され、Mac の外には出ません。
  • ライセンスキーと試用期間の開始日（無料版からお使いの Mac では、その印）。macOS のキーチェーンに保存されます。ライセンスの確認はアプリの中だけで行い、通信はしません。

購入したとき

決済は販売代行会社が処理します。カード番号などの決済情報は同社が扱い、当方は受け取りません。同社のプライバシーポリシーが適用されます。当方が知るのは、ライセンスの発行に必要な範囲のみです。

このウェブサイト

本サイトは GitHub Pages でホストされています。アクセスに伴い GitHub がログ（IP アドレス等）を取得します。当方は解析ツールや広告、Cookie を使用していません。
